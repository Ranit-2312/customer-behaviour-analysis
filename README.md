# 📊 Customer Behaviour Analysis

## 📌 Overview

This project presents a complete data analytics pipeline to analyze customer behavior using multiple tools and technologies. It begins with Exploratory Data Analysis (EDA), followed by data storage in MySQL, SQL-based analysis, and visualization through an interactive Power BI dashboard.

The goal is to extract meaningful insights about customer patterns, preferences, and trends to support data-driven decision-making.

---

## 🔄 Project Workflow

1. **Exploratory Data Analysis (EDA)**

   * Performed using Jupyter Notebook
   * Data cleaning, preprocessing, and visualization
   * Handling missing values and outliers
   * Understanding distributions and relationships

2. **Data Storage (MySQL)**

   * Cleaned dataset imported into MySQL database
   * Structured tables created for efficient querying

3. **SQL Analysis**

   * Business questions solved using SQL queries
   * Aggregations, joins, filtering, and grouping
   * Insights derived directly from the database

4. **Data Visualization (Power BI)**

   * MySQL database connected to Power BI
   * Interactive dashboards created
   * Visual representation of key metrics and trends

5. **Presentation**

   * Final insights summarized in a presentation
   * Business recommendations included

## 🚀 How to Run the Project

### 1. Clone Repository

```bash
git clone https://github.com/Ranit-2312/customer-behaviour-analysis.git
cd customer-behaviour-analysis
```

### 2. Run EDA Notebook

* Open Jupyter Notebook
* Run `customer behaviour.ipynb`

### 3. Import Data into MySQL

* Create database
* Import cleaned dataset
* Run SQL scripts from `/SQL` folder

### 4. Open Power BI Dashboard

* Open `.pbix` file in Power BI Desktop
* Connect to MySQL if needed
